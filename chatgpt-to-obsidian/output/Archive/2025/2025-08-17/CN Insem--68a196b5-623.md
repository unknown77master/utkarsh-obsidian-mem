# 📘 Unit I – Fundamentals of Computer Networks 

### 1. Definition of Computer Network 
- A **computer network** is a collection of interconnected devices (computers, servers, etc.) that share resources and exchange data through communication links. 

### 2. Uses of Computer Networks 
- **Resource Sharing** (files, printers, software) 
- **Communication** (emails, video calls, chat) 
- **Data sharing** (centralized database) 
- **E-commerce** & online services 
- **Remote access & collaboration** 

### 3. Network Devices 
- **Bridge** – Connects two similar networks (LAN segments), filters traffic. 
- **Switch** – Multiport device, forwards frames using MAC address, reduces collisions. 
- **Router** – Connects different networks, forwards packets using IP addresses. 
- **Gateway** – Connects two dissimilar networks (different protocols). 
- **Access Point (AP)** – Provides wireless connectivity to devices (Wi-Fi). 

### 4. Network Topologies 
- **Bus** – Single backbone cable, easy but failure-prone. 
- **Star** – Central hub, reliable, easy to manage. 
- **Ring** – Circular path, each device connected to 2 others, failure of one affects all. 
- **Tree** – Combination of star & bus, hierarchical. 
- **Mesh** – Each device connected to every other, very reliable, costly. 
- **Hybrid** – Combination of topologies (star-bus, star-ring). 

### 5. Types of Networks 
- **LAN** – Local area, small area (college, office). 
- **MAN** – Metropolitan area (city-wide). 
- **WAN** – Wide area (country/continent, e.g., Internet). 
- **PAN** – Personal area (Bluetooth, hotspot). 
- **Ad-Hoc** – Temporary network without infrastructure (mobile-to-mobile). 

### 6. Network Software & Protocol 
- **Protocol** – Set of rules for communication (TCP, IP, HTTP, FTP). 
- **Design issues** – Reliability, addressing, error control, flow control, congestion control. 

### 7. Transmission Media 
- **Guided (wired):** Twisted pair, Coaxial, Fiber optic. 
- **Unguided (wireless):** Radio waves, Microwaves, Infrared, Satellite. 

### 8. Network Architecture 
- **Client-Server** – Centralized server provides services. 
- **Peer-to-Peer (P2P)** – Each device acts as client & server. 
- **Hybrid** – Combination of both. 

### 9. Network Models 
- **OSI Model (7 layers):** Physical → Data Link → Network → Transport → Session → Presentation → Application. 
- **TCP/IP Model (4 layers):** Network Interface → Internet → Transport → Application. 

### 10. Types of Addressing 
- **Physical Addressing (MAC):** Unique hardware address. 
- **Logical Addressing (IP):** Identifies device location in network. 
- **Port Addressing:** Identifies specific process/application (e.g., port 80 = HTTP). 
- **Other addressing:** URL, Email address, etc.

# ✍️ Q3 

### (a) Explain in brief FHSS and DSSS. (10 Marks) 

**Spread Spectrum:** 
It is a technique in which the transmitted signal is spread over a wider bandwidth than the minimum required. This increases security, reduces interference, and provides robustness against noise. 

**1. Frequency Hopping Spread Spectrum (FHSS):** 
- In FHSS, the signal rapidly changes (“hops”) from one carrier frequency to another within a large frequency band. 
- A **pseudo-random hopping sequence** determines the order of frequency changes. 
- Each frequency is used only for a short duration, then the transmitter and receiver hop to the next frequency. 
- **Advantages:** 
 - Resistant to narrowband interference. 
 - Provides better security (difficult to intercept). 
 - Robust against multipath fading. 
- **Example:** Bluetooth, military communication. 

**2. Direct Sequence Spread Spectrum (DSSS):** 
- In DSSS, each bit of data is multiplied with a **pseudo-noise (PN) code sequence** called “chips.” 
- This increases the bandwidth of the signal significantly. 
- Even if interference occurs, due to redundancy of spreading, the original data can be retrieved. 
- **Advantages:** 
 - High noise immunity. 
 - Provides error detection and correction. 
 - Difficult to jam or intercept. 
- **Example:** Wi-Fi (IEEE 802.11b), GPS.

# ✍️ Frequency Division Multiplexing (FDM) – 10 Marks 

### 1. Definition 
Frequency Division Multiplexing (FDM) is a **multiplexing technique** in which multiple signals are transmitted simultaneously over a single communication channel by **assigning each signal a unique frequency band (carrier frequency)** within the available bandwidth. 

---

### 2. Working Principle 
- The total bandwidth of the channel is **divided into multiple smaller frequency bands**. 
- Each user/signal is allocated a **separate frequency slot**. 
- Signals are modulated with different carrier frequencies and combined (multiplexed) before transmission. 
- At the receiver side, **demultiplexing** is done using band-pass filters to separate signals. 
- **Guard bands** (unused small frequency gaps) are placed between adjacent channels to avoid overlapping/interference. 

---

### 3. Diagram (Exam Sketch) 

```
|---Ch1---| |---Ch2---| |---Ch3---| ... |---Chn---|
 f1 f2 f3 fn
--------------------------------------------------- Frequency Spectrum
```

Each channel is given a fixed range of frequencies. 

---

### 4. Features 
- Works with **analog signals**. 
- Requires **large bandwidth**. 
- Transmission is **simultaneous and parallel**. 
- Guard bands are essential to prevent crosstalk. 

---

### 5. Advantages 
- Simple technique, easy to implement. 
- Allows multiple users to share a single channel. 
- Continuous transmission without waiting (unlike time-sharing). 
- Less delay compared to TDM. 

---

### 6. Disadvantages 
- Requires **large bandwidth**. 
- Inefficient if one channel is idle (frequency remains unused). 
- Crosstalk may occur if guard bands are insufficient. 
- Complex and costly hardware due to filters and modulators. 

---

### 7. Applications 
- **Radio broadcasting:** Different radio stations transmit on different frequencies (FM 90.4 MHz, 91.1 MHz, etc.). 
- **Television broadcasting:** Each TV channel occupies separate frequency bands. 
- **Telephone networks (early analog):** Voice channels multiplexed on long-distance trunks. 
- **Satellite communication.** 

---

✅ **Conclusion:** 
FDM is a widely used multiplexing technique in analog communication systems where multiple signals share the same medium simultaneously by operating on **different frequency ranges**.

# ✍️ Q14) Explain Different Types of Addressing Methods (10 Marks)

In computer networks, **addressing** is the process of identifying devices, processes, and applications to ensure that data is delivered correctly from the sender to the receiver.

# ✍️ Layers in OSI Model (PDNTSPA Acronym) – 10 Marks 

The **OSI (Open Systems Interconnection) model** is a **conceptual framework** developed by ISO to standardize network communication. It has **7 layers**, each responsible for a specific function.

**(Physical → Data Link → Network → Transport → Session → Presentation → Application)**

- Concerned with **transmission of raw bits (0s and 1s)** over the medium.

 - Transmission media (cables, radio waves, fiber). 
 - Voltage levels, timing, data rates.

- Ensures **reliable node-to-node delivery**. 
- Functions: 
 - Framing (dividing data into frames). 
 - Error detection & correction (CRC). 
 - Flow control. 
 - MAC addressing. 
- Example: Ethernet (MAC), PPP. 

---

### 3. **Network Layer (N)** 
- Responsible for **source-to-destination delivery across multiple networks**. 
- Functions: 
 - Logical addressing (IP). 
 - Routing and forwarding. 
 - Congestion control. 
- Example: IP (IPv4/IPv6), ICMP, OSPF, RIP. 

---

### 4. **Transport Layer (T)** 
- Provides **end-to-end reliable delivery** of data. 
- Functions: 
 - Segmentation and reassembly. 
 - Error recovery. 
 - Flow control. 
 - Port addressing (identifies process).

 - Session establishment, maintenance, termination.

# Definition
CSMA/CA stands for:

## Carrier Sense Multiple Access with Collision Avoidance

It is a network access protocol used mainly in **wireless LANs (IEEE 802.11 Wi-Fi)** to reduce collisions before they occur.

Unlike CSMA/CD used in Ethernet, wireless stations cannot detect collisions easily. Therefore, CSMA/CA tries to avoid collisions.

---

# Working of CSMA/CA

## Step 1: Carrier Sensing
- A station first checks whether the channel is free or busy.

## Step 2: Wait if Busy
- If channel is busy, the station waits.

## Step 3: Interframe Space (IFS)
- When channel becomes idle, station waits for a fixed time called IFS.

## Step 4: Random Backoff
- Station selects a random backoff timer.
- Countdown begins only when channel is idle.

## Step 5: Data Transmission
- When timer reaches zero, station transmits data.

## Step 6: Acknowledgment (ACK)
- Receiver sends ACK after successful reception.
- If ACK not received, sender assumes collision occurred and retransmits.

---

# RTS/CTS Mechanism

To further avoid collisions, CSMA/CA uses:

- **RTS (Request to Send)**
- **CTS (Clear to Send)**

## Process
1. Sender sends RTS.
2. Receiver replies CTS.
3. Other stations remain silent.
4. Data transmission occurs safely.

This helps solve the **hidden terminal problem**.

---

# Hidden Terminal Problem
Occurs when two stations cannot hear each other but both communicate with same access point, causing collision.

CSMA/CA reduces this using RTS/CTS.

---

# Advantages
- Reduces collisions.
- Efficient for wireless communication.
- Improves network reliability.

---

# Disadvantages
- Extra delay due to waiting and backoff.
- Lower efficiency under heavy traffic.

---

# Applications
- Wi-Fi networks.
- Wireless LANs.
- Mobile communication systems.

---

# Conclusion
CSMA/CA is an important wireless access protocol that minimizes collisions using carrier sensing, backoff timers, acknowledgments, and RTS/CTS mechanisms, making wireless communication reliable and efficient.

When multiple devices transmit simultaneously, a collision occurs. The algorithm determines how long each station should wait before retransmitting.

# Working of Binary Exponential Back-off

## Step 1: Collision Occurs
Two or more stations transmit data at the same time.

---

## Step 2: Collision Detection
Stations detect collision on the network.

---

## Step 3: Send Jam Signal
A jam signal is transmitted so all stations know that collision has occurred.

---

## Step 4: Random Waiting Time
Each station waits for a random amount of time before retransmitting.

The waiting time is calculated using:

\\[
\text{Backoff Time} = K \times T
\\]

Where:
- \(K\) = random number
- \(T\) = slot time

---

# Binary Exponential Rule

After each collision:
- Range of random numbers doubles.

If collision count = \(n\)

Then:

\\[
K = 0 \text{ to } (2^n - 1)
\\]

---

# Example

## First Collision
\\[
K = 0 \text{ or } 1
\\]

## Second Collision
\\[
K = 0 \text{ to } 3
\\]

## Third Collision
\\[
K = 0 \text{ to } 7
\\]

Thus, waiting time increases exponentially after repeated collisions.

---

# Purpose
The algorithm reduces the probability of repeated collisions by increasing waiting time after every collision.

---

# Use in Ethernet
- Used in IEEE 802.3 Ethernet.
- Works with CSMA/CD protocol.
- Improves network efficiency during heavy traffic.

---

# Conclusion
Binary Exponential Back-off is an important collision recovery mechanism in Ethernet networks that minimizes repeated collisions by increasing random waiting time exponentially after each collision.

# ICMP (Internet Control Message Protocol)

ICMP is a network layer protocol used for:
- Error reporting
- Network diagnostics
- Sending control messages

It works along with the IP protocol.

Examples:
- `ping`
- `traceroute`

---

# ICMP Header Format

## Diagram

```text id="3nk9km"
 0 8 16 31
 ----------------------------------------------------------------
| Type | Code | Checksum |
 ----------------------------------------------------------------
| Rest of Header |
 ----------------------------------------------------------------
| Data |
 ----------------------------------------------------------------
```

---

# Explanation of Fields

# 1. Type Field (8 bits)

- Identifies the type of ICMP message.
- Specifies the purpose of the message.

## Examples

| Type | Meaning |
|---|---|
| 0 | Echo Reply |
| 3 | Destination Unreachable |
| 5 | Redirect Message |
| 8 | Echo Request |
| 11 | Time Exceeded |

Example:
- `ping` uses:
 - Type 8 → Echo Request
 - Type 0 → Echo Reply

---

# 2. Code Field (8 bits)

- Provides additional information about the message type.
- Refines the meaning of Type field.

## Example
For Destination Unreachable (Type 3):

| Code | Meaning |
|---|---|
| 0 | Network Unreachable |
| 1 | Host Unreachable |
| 3 | Port Unreachable |

---

# 3. Checksum Field (16 bits)

- Used for error detection.
- Calculated on entire ICMP message.
- Receiver verifies checksum to detect corruption.

---

# 4. Rest of Header

- Size and meaning depend on ICMP message type.
- May contain:
 - Identifier
 - Sequence number
 - Gateway address
 - Pointer field

Example:
- In Echo Request/Reply:
 - Identifier
 - Sequence Number

---

# 5. Data Field

- Contains additional information.
- Used to carry payload data.
- In `ping`, this field contains test data.

---

# Working of ICMP

## Example: Ping Operation

1. Source sends ICMP Echo Request.
2. Destination receives request.
3. Destination sends ICMP Echo Reply.
4. Round Trip Time (RTT) measured.

---

# Common ICMP Messages

| Message Type | Purpose |
|---|---|
| Echo Request | Connectivity testing |
| Echo Reply | Response to ping |
| Destination Unreachable | Packet cannot reach destination |
| Time Exceeded | TTL expired |
| Redirect | Better route available |

---

# Applications of ICMP

- Error reporting
- Network troubleshooting
- Path discovery
- Connectivity testing
- Congestion reporting

---

# Conclusion

ICMP is an important protocol used for reporting errors and diagnosing network problems. Its header contains fields like Type, Code, Checksum, Rest of Header, and Data, which help identify and manage network communication issues effectively.
