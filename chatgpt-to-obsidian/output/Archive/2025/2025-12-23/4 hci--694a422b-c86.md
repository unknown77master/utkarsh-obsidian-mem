## **Q3 (a) Discuss the GOMS Models with example. \[6\]**

**Answer:**

The **GOMS model** is a predictive model used in **Human–Computer Interaction (HCI)** to analyze and estimate how users perform tasks on a system. The term **GOMS** stands for **Goals, Operators, Methods, and Selection rules**. It is mainly applied to **expert users** performing **well-defined tasks** and helps designers evaluate usability in terms of efficiency.

### **Components of GOMS:**

1. **Goals** 
 Goals represent what the user wants to achieve. 
 *Example:* “Save a document.”

2. **Operators** 
 Operators are the basic actions performed by the user, such as keystrokes, mouse clicks, or mental operations. 
 *Example:* Pressing `Ctrl + S`, moving the mouse.

3. **Methods** 
 Methods are sequences of operators used to accomplish a goal. 
 *Example:* 
 - Method 1: Click *File → Save* 
 - Method 2: Press `Ctrl + S`

4. **Selection Rules** 
 Selection rules determine which method is chosen when multiple methods are available. 
 *Example:* “If keyboard is available, use shortcut; otherwise use menu.”

### **Example: Saving a File in a Text Editor**

- **Goal:** Save the document 
- **Methods:** 
 - Method A: Click *File → Save* 
 - Method B: Press `Ctrl + S` 
- **Operators:** Mouse movement, mouse click, keystroke 
- **Selection Rule:** Use keyboard shortcut if user is experienced

### **Conclusion:**
GOMS models are useful for **predicting task completion time**, comparing interface designs, and identifying inefficiencies. However, they are limited to expert behavior and do not account for learning or errors.

## **Q3 (b) Elaborate the objective measures of Usability, formative and summative evaluation. \[6\]**

**Answer:**

### **Objective Measures of Usability**

Objective measures are **quantifiable and observable metrics** used to evaluate how usable a system is. Common objective measures include:

1. **Efficiency** – Time taken to complete a task 
2. **Effectiveness** – Accuracy and success rate 
3. **Error Rate** – Number and severity of errors 
4. **Learnability** – Time taken to learn the system 
5. **Productivity** – Number of tasks completed per unit time 

These measures provide **data-driven evidence** of usability performance.

---

### **Formative Evaluation**

Formative evaluation is conducted **during the design and development phase** to improve the system.

**Characteristics:**
- Performed early and continuously 
- Focuses on identifying usability problems 
- Uses prototypes and mock-ups 

**Examples:**
- Heuristic evaluation 
- Cognitive walkthrough 
- Think-aloud testing 

**Purpose:** To refine and improve the design before final implementation.

---

### **Summative Evaluation**

Summative evaluation is conducted **after system development** to assess overall usability.

**Characteristics:**
- Performed at the end of development 
- Compares system against usability benchmarks 
- Focuses on final performance 

**Examples:**
- Usability testing with real users 
- Performance measurement 
- User satisfaction surveys 

**Purpose:** To validate whether usability goals have been achieved.

---

### **Conclusion:**
Objective usability measures combined with formative and summative evaluations ensure both **continuous improvement** and **final quality assurance** of interactive systems.

## **Q3 (c) Explain Cognitive Walkthrough in detail. \[5\]**

**Answer:**

A **Cognitive Walkthrough** is an **inspection-based usability evaluation technique** that focuses on how easily **new users** can learn a system by exploration. It evaluates the system from a **user’s cognitive perspective**.

### **Procedure of Cognitive Walkthrough:**

1. **Define the Users** 
 Identify user characteristics, knowledge level, and experience.

2. **Define the Task** 
 Select representative tasks users are expected to perform.

3. **Walkthrough the Task Step-by-Step** 
 For each step, evaluators ask four key questions:
 - Will the user try to achieve the right goal?
 - Will the user notice the correct action?
 - Will the user associate the action with the desired outcome?
 - Will the user receive appropriate feedback?

4. **Identify Usability Problems** 
 Any step that causes confusion or failure is noted.

### **Advantages:**
- Focuses on learnability 
- No real users required 
- Useful in early design stages 

### **Limitations:**
- Does not evaluate expert usage 
- Time-consuming for complex systems 

### **Conclusion:**
Cognitive walkthroughs are effective for detecting **learnability issues** and improving first-time user experience.

Heuristic evaluation is an **expert-based usability inspection method** where evaluators examine an interface using predefined usability principles (heuristics), such as Nielsen’s heuristics.

**Advantages:**
- Low cost 
- Quick to perform 
- No users required 

**Limitations:**
- Depends on evaluator expertise 
- May miss user-specific issues 

---

Laboratory usability testing involves observing users performing tasks in a **controlled environment**.

**Advantages:**
- Accurate data collection 
- Controlled variables 
- Supports detailed analysis 

**Limitations:**
- Artificial environment 
- Higher cost and setup effort 

---

### **Conclusion:**
Heuristic evaluation identifies **early design issues**, while laboratory usability testing provides **empirical user performance data**. Both methods complement each other in usability evaluation.

### **Principles of Universal Design**

1. **Equitable Use** 
 Design is useful to people with diverse abilities.

2. **Flexibility in Use** 
 Accommodates different user preferences and abilities.

 Easy to understand regardless of experience.

 Minimizes hazards and consequences of mistakes.

 Can be used comfortably with minimal fatigue.

7. **Size and Space for Approach and Use** 
 Appropriate space for interaction regardless of user posture.

Universal design enhances accessibility, usability, and inclusiveness of interactive systems.

Explain vision based hand gesture recognition system using HCI Paradigms for 6 marks

## Assistant

**Answer:**

A **vision-based hand gesture recognition system** is an advanced **Human–Computer Interaction (HCI)** technique that enables users to interact with computers using **hand movements captured through cameras**, without requiring physical contact devices such as a mouse or keyboard. This system interprets human gestures as input commands, thereby supporting **natural and intuitive interaction**.

### **Explanation using HCI Paradigms**

The working and design of a vision-based hand gesture recognition system can be explained using the following **HCI paradigms**:

1. **Desktop Paradigm (WIMP Extension)** 
 In this paradigm, hand gestures act as substitutes for traditional input devices. For example, moving the hand in air can replace mouse movement, while specific gestures can represent clicking or scrolling operations.

2. **Direct Manipulation Paradigm** 
 Users interact directly with on-screen objects using hand gestures. Objects respond immediately to gestures such as grab, drag, rotate, or zoom, providing continuous feedback and reducing cognitive load.

3. **Natural User Interface (NUI) Paradigm** 
 Vision-based gesture recognition aligns strongly with NUI, as it leverages natural human hand movements. The interaction becomes intuitive and requires minimal learning, improving user experience and accessibility.

4. **Multimodal Interaction Paradigm** 
 Gesture recognition systems are often combined with other input modes such as voice or facial expressions. This improves robustness and allows flexible interaction in diverse environments.

5. **Ubiquitous Computing Paradigm** 
 These systems support interaction in smart environments such as smart homes, virtual reality, and public displays, enabling seamless and context-aware computing.

### **System Working Overview**

- A **camera** captures real-time hand movements.
- **Image processing and computer vision algorithms** segment the hand from the background.
- **Feature extraction** identifies gesture patterns.
- A **classifier** maps gestures to system commands.
- The system provides **visual or auditory feedback** to the user.

### **Conclusion**

In conclusion, a vision-based hand gesture recognition system represents a shift towards **natural, direct, and device-free interaction** in HCI. By integrating multiple HCI paradigms, it enhances usability, accessibility, and user engagement, making it suitable for modern interactive systems.
