# Sum of two numbers

## User

Write code to take 2 number as input and show their sum on alert box in JS

## Assistant

Certainly. Below is the JavaScript code that takes two numbers as input from the user using `prompt()` and then displays their sum using an `alert()` box:

```javascript
// Take two numbers as input
let num1 = prompt("Enter the first number:");
let num2 = prompt("Enter the second number:");

// Convert input strings to numbers
let sum = Number(num1) + Number(num2);

// Show the sum in an alert box
alert("The sum is: " + sum);
```

### Explanation:
- `prompt()` is used to take input from the user. It returns a **string**.
- `Number()` is used to convert the input to a numeric type.
- `alert()` displays the result in a pop-up alert box.
