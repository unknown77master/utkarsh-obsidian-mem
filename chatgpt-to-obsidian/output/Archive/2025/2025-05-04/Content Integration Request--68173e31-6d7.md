## 2. Literature Survey 
Fake news detection has attracted significant research interest in recent years, leveraging natural language processing (NLP) and machine learning to automatically classify news veracity. In practice, standard classifiers such as Logistic Regression, Decision Trees, Random Forests, Naïve Bayes, and Support Vector Machines (SVM) have all been applied to fake news corpora【12†L47-L54】【26†L42-L49】. Ayankemi et al. To process the text, most approaches use NLP feature engineering. Common techniques include bag-of-words, TF-IDF weighting, n-grams, and word embeddings (e.g. Word2Vec) to convert text into numeric vectors. For instance, one implementation uses TF-IDF to assign higher weight to rare but important words【36†L138-L140】. NLP preprocessing (tokenization, stop-word removal, punctuation stripping, stemming/lemmatization) is typically applied before feature extraction【36†L120-L129】. Once features are obtained, models are evaluated using standard metrics (accuracy, precision, recall). Shaikh and Patil (2020) reported that an SVM with TF-IDF features achieved about 95% accuracy, outperforming Naïve Bayes and other linear models on a news dataset【28†L151-L160】. 

In addition to shallow models, deep-learning approaches have also been explored. Surveys indicate that recurrent neural networks (LSTM/GRU), convolutional neural networks, and transformer-based models can capture complex linguistic patterns and have achieved very high accuracy (often above 95%) on benchmark datasets【12†L47-L54】【52†L173-L181】. In summary, the literature confirms that machine learning with NLP features is a viable strategy for fake news detection【52†L149-L158】【26†L42-L49】, but also highlights challenges in generalizing to real-world settings and emerging forms of misinformation.

## 5. System Design 
The system is designed as a data processing and classification pipeline, comprising the following modules: 

- **Data Acquisition:** Load the dataset of news articles, which typically consists of two parts (e.g. *Fake.csv* and *True.csv*) with columns for title, text, date, etc. We merge these into a single labeled dataset. 
- **Preprocessing:** Clean and normalize the text to remove noise. As described in prior work, this involves steps such as lowercasing all text, removing punctuation and non-alphabetic characters, eliminating stopwords, and applying stemming or lemmatization【36†L120-L129】. These NLP preprocessing techniques reduce irrelevant information and standardize the input. 
- **Feature Engineering:** Convert the cleaned text into numerical feature vectors. A common approach is TF-IDF (Term Frequency–Inverse Document Frequency) vectorization【36†L138-L140】. TF-IDF transforms each article into a weighted word-count vector, where higher weights indicate words that are important in that document but less common across all documents. This representation allows the machine learning model to quantify textual content. 
- **Model Training:** Split the data into training (e.g. 80%) and testing sets (20%). We then train multiple classifiers on the training set. In this project, the chosen models are:
 - *Logistic Regression:* A linear model for binary classification. 
 - *Decision Tree:* A tree-structured classifier that recursively splits features. 
 - *Random Forest:* An ensemble of randomized decision trees. 
 These models are implemented using scikit-learn. Each model is trained on the TF-IDF feature matrix and tuned via default or specified hyperparameters. 
- **Model Evaluation:** After training, we evaluate each classifier on the test set. Performance is measured using accuracy, precision, recall, and F1-score. The best-performing model is identified for final deployment. For example, Ayankemi et al. achieved around 99% accuracy with Decision Trees【26†L42-L49】, suggesting this model may be very effective if implemented similarly. 
- **Prediction:** The selected model can then classify new, unseen news articles. Given an input text, it is preprocessed and vectorized as above, and the model predicts *real* or *fake*. 

These components can be visualized as a flow: **Data Collection → Preprocessing (NLTK) → Feature Extraction (TF-IDF) → Model Training (LR/DT/RF) → Evaluation/Deployment**. Each step plays a crucial role in the system’s overall performance. All code modules (data loader, preprocess script, training routines) will be orchestrated to automate this pipeline.
