In modern Node.js backend development, the packages **dotenv, express, cors, and mongoose** are commonly used to build secure and scalable web applications.

### 1. dotenv

```js
require("dotenv").config();
```

**Benefit:**

### 2. express

`express` is a lightweight Node.js web framework used to create servers and APIs.

**Purpose:**
- To handle HTTP requests and responses.
- To define routes and middleware easily.

**Example:**
```js
const express = require("express");
const app = express();

app.get("/", (req, res) => {
 res.send("Hello World");
});
```

**Benefit:** 
It simplifies backend development and improves productivity.

---

### 3. cors

`cors` stands for Cross-Origin Resource Sharing.

**Purpose:**
- To allow or restrict requests from different domains.
- To enable frontend (React, Angular, etc.) to communicate with backend.

**Example:**
```js
const cors = require("cors");
app.use(cors());
```

**Benefit:** 
It prevents browser security errors while maintaining controlled access.

---

### 4. mongoose

`mongoose` is an Object Data Modeling (ODM) library for MongoDB.

**Purpose:**
- To connect Node.js with MongoDB.
- To define schemas and models.

```js
const mongoose = require("mongoose");

mongoose.connect(process.env.MONGO_URL);

 name: String,
 age: Number
```

**Benefit:** 
It provides structure, validation, and query support for MongoDB.

### Difference between

```js
import express, { json } from "express";
```
and
```js
const express = require("express");
```

---

### 1. `import express, { json } from "express";`

This syntax belongs to **ES Modules (ESM)**.

- `express` → default export (Express app function)
- `{ json }` → named export (middleware for JSON parsing)

**Usage:**
```js
import express, { json } from "express";

const app = express();
app.use(json());
```

**Requirements:**
- `"type": "module"` in `package.json`
- OR file extension `.mjs`

**Feature:** 
Modern JavaScript standard, supports tree-shaking and cleaner syntax.

---

### 2. `const express = require("express");`

This syntax belongs to **CommonJS**.

**Usage:**
```js
const express = require("express");

const app = express();
app.use(express.json());
```

**Feature:** 
Traditional Node.js module system, widely used in older projects.

---

### Key Differences

| Aspect | import | require |
|------|-------|--------|
| Module system | ES Modules | CommonJS |
| Syntax | Modern JS | Older Node style |
| Named imports | Supported | Not directly |
| Async support | Static loading | Dynamic loading |
| package.json | Needs `"type":"module"` | No config needed |

---

### Important Correction

This is **wrong**:

```js
import express from "express";
const express = require("express");
```

Because both use **different module systems** and will cause runtime conflict.

---

### Conclusion

Both statements import Express, but:

- `import` is modern ES module syntax.
- `require` is legacy CommonJS syntax.

They must **not be mixed in the same project**.

- `User.deleteOne()`

It is created when you fetch or insert data using the model.

### Example:

```js

```

Here:

> `user` is a **Document**

It represents one MongoDB record.

| Created using schema | Returned from model |
| Capital letter (User) | Small letter (user) |

| Example: User.find() | Example: user.save() |

**Vim keybindings** are a set of **keyboard shortcuts and command patterns** derived from the **Vim text editor** that allow users to edit text **without using a mouse** and with minimal hand movement. These keybindings are designed to improve **speed, efficiency, and precision** while coding or writing.

---

### Explanation (Student-style, exam-ready)

Vim keybindings refer to the keyboard-based control system used in the Vim editor, where different keys perform different actions depending on the **current mode** of the editor. Instead of menus or mouse clicks, users interact entirely through the keyboard.

---

### Core Concept: **Modes in Vim**

Vim operates in multiple modes:

1. **Normal Mode** 
 - Used for navigation and commands 
 - Default mode when Vim starts 

2. **Insert Mode** 
 - Used for typing text 
 - Entered using keys like `i`, `a`, `o`

3. **Visual Mode** 
 - Used for selecting text 
 - Entered using `v`, `V`, or `Ctrl + v`

4. **Command Mode** 
 - Used for file operations 
 - Entered using `:`

---

### Common Vim Keybindings

| Key | Function |
|---|---|
| `h j k l` | Move left, down, up, right |
| `i` | Insert before cursor |
| `a` | Insert after cursor |
| `dd` | Delete current line |
| `yy` | Copy (yank) line |
| `p` | Paste |
| `u` | Undo |
| `Ctrl + r` | Redo |
| `:w` | Save file |
| `:q` | Quit |
| `:wq` | Save and quit |

### Vim Keybindings Outside Vim

Many modern tools support Vim-style controls:

- VS Code → *Vim extension*
- JetBrains IDEs → *IdeaVim*
- Browsers → *Vimium*
- Terminals → *Zsh vi-mode*
