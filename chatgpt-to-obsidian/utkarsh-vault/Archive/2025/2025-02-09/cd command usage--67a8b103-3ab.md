# cd command usage

## User

using cd command i want to go back how do i do it

Please write in English language.

## Assistant

To go back (move up one directory) using the `cd` command in a terminal, use: 

```bash
cd ..
```

This moves you one level up in the directory structure. If you want to go back multiple levels, use multiple `..`, like this:

```bash
cd ../..
```

This moves you up two levels. 

If you want to return to your home directory, use:

```bash
cd ~
```

If you want to return to the previous directory you were in, use:

```bash
cd -
```

## Assistant

To go to a specific folder using the `cd` command, use the following syntax: 

```bash
cd /path/to/folder
```

### Examples: 
1. **Go to a folder inside the current directory:** 
 ```bash
 cd foldername
 ```
2. **Go to a folder using an absolute path:** 
 ```bash
 cd /home/user/Documents
 ```
3. **Go to a folder using a relative path:** 
 ```bash
 cd ../foldername # Move up one level, then into "foldername"
 ```
4. **Go to the home directory:** 
 ```bash
 cd ~
 ```
5. **Go to the root directory:** 
 ```bash
 cd /
 ```
