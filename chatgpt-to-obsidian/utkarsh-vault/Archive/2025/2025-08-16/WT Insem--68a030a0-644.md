## **Different Types of CSS**

CSS (Cascading Style Sheets) can be applied in **three different ways**: 

---

### **1. Inline CSS** 
- Applied **directly inside an HTML tag** using the `style` attribute. 
- Used for quick styling of a single element. 
- Not recommended for large projects (less reusable). 

**Example:** 
```html
<p style="color: blue; font-size: 18px;">This is inline CSS.</p>
```

---

### **2. Internal CSS** 
- Written **inside the `<style>` tag** within the `<head>` section of an HTML file. 
- Styles apply only to that single webpage. 
- Good for small websites with limited pages. 

**Example:** 
```html
<!DOCTYPE html>
<html>
<head>
 <style>
 h1 {
 color: green;
 text-align: center;
 }
 p {
 font-size: 16px;
 }
 </style>
</head>
<body>
 <h1>This is Internal CSS</h1>
 <p>Example of internal stylesheet.</p>
</body>
</html>
```

---

### **3. External CSS** 
- CSS is written in a **separate `.css` file** and linked to the HTML using `<link>` tag in `<head>`. 
- Best for large projects with multiple web pages, as one CSS file can style all pages. 
- Provides **reusability** and better maintenance. 

**Example:** 

**index.html** 
```html
<!DOCTYPE html>
<html>
<head>
 <link rel="stylesheet" type="text/css" href="style.css">
</head>
<body>
 <h1>This is External CSS</h1>
 <p>Example of external stylesheet.</p>
</body>
</html>
```

**style.css** 
```css
h1 {
 color: red;
 text-align: center;
}
p {
 font-size: 18px;
}
```

---

### **Conclusion:** 
- **Inline CSS**: Element-specific, quick but not reusable. 
- **Internal CSS**: Page-specific, manageable for small projects. 
- **External CSS**: Project-wide, best for large and maintainable websites.
