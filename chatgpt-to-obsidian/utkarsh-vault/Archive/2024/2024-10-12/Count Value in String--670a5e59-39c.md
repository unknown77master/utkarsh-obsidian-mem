## Assistant

To count the occurrences of a particular value (or substring) in a string in Python, you can use the `count()` method. Here’s the syntax and an example:

### Syntax:
```python
string.count(substring)
```

- `string`: The string in which you want to count the occurrences.
- `substring`: The specific value (substring) you want to count.

### Example:
```python
text = "Hello, world! Hello, everyone!"
count_hello = text.count("Hello")
print(count_hello)
```

### Output:
```
2
```

In this example, the program counts how many times `"Hello"` appears in the string `text`.
