## User

how to go to previous folder in cmd

## Assistant

**Answer (as written in an exam / practical notebook style):**

To go to the previous (parent) folder in Command Prompt (CMD), the following command is used:

```
cd ..
```

**Explanation:** 
The command `cd` stands for *change directory*. The symbol `..` represents the parent directory of the current folder. Therefore, `cd ..` moves the user one level back in the folder hierarchy.

**Example:**

If the current directory is:
```
C:\Users\Utkarsh\Documents\Projects
```

After executing:
```
cd ..
```

The directory becomes:
```
C:\Users\Utkarsh\Documents
```

**Note:** 
To go back multiple folders, the command can be repeated, for example:
```
cd ..\..
```

This moves two levels up in the directory structure.
