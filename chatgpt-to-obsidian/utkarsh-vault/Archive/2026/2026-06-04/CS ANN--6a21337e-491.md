## a) Explain Diffie-Hellman Key Exchange Algorithm with Example. \[6\]

### Diffie-Hellman Key Exchange

Diffie-Hellman Key Exchange is a public key cryptographic algorithm used to securely establish a shared secret key between two users over an insecure communication channel. The algorithm allows two parties to generate the same secret key without transmitting the key itself over the network.

### Algorithm

1. Two users agree on:
 - A large prime number **q**
 - A primitive root **α** of q

2. User A selects a private key **XA** and computes:
 \\[
 YA = \alpha^{XA}\; mod\; q
 \\]

3. User B selects a private key **XB** and computes:
 \\[
 YB = \alpha^{XB}\; mod\; q
 \\]

4. Both users exchange their public keys.

5. User A computes:
 \\[
 K = (YB)^{XA}\; mod\; q
 \\]

6. User B computes:
 \\[
 K = (YA)^{XB}\; mod\; q
 \\]

7. Both obtain the same secret key K.

### Example

Given:

- Prime number \(q = 17\)
- Primitive root \(\alpha = 5\)
- A's private key \(XA = 4\)
- B's private key \(XB = 6\)

**Step 1: Calculate Public Keys**

For A:

\\[
YA = 5^4 \;mod\;17
\\]

\\[
YA = 625\;mod\;17 = 13
\\]

For B:

\\[
YB = 5^6 \;mod\;17
\\]

\\[
YB = 15625\;mod\;17 = 2
\\]

**Step 2: Exchange Public Keys**

- A sends 13 to B
- B sends 2 to A

**Step 3: Compute Shared Secret Key**

At A:

\\[
K=(2)^4\;mod\;17
\\]

\\[
K=16
\\]

At B:

\\[
K=(13)^6\;mod\;17
\\]

\\[
K=16
\\]

Therefore,

\\[
\boxed{Shared\ Secret\ Key = 16}
\\]

### Conclusion

Diffie-Hellman enables two communicating parties to establish a common secret key without transmitting the actual key. It forms the foundation of many secure communication protocols such as VPNs, SSL/TLS, and SSH.

## c) Explain the Operations of Kerberos. \[6\]

### Kerberos

Kerberos is a trusted third-party network authentication protocol developed at MIT. It provides secure authentication over insecure networks using secret-key cryptography and a ticket-based mechanism.

### Components of Kerberos

1. **Client/User**
2. **Authentication Server (AS)**
3. **Ticket Granting Server (TGS)**
4. **Service Server (SS)**
5. **Kerberos Database**

### Operation of Kerberos

#### Step 1: User Login

The user enters username and password. The password is used to generate a secret key.

#### Step 2: Request to Authentication Server

The client sends a request to the Authentication Server (AS) for authentication.

#### Step 3: Ticket Granting Ticket (TGT)

After verifying the user, AS sends:

- Session Key
- Ticket Granting Ticket (TGT)

The TGT is encrypted using the secret key of the TGS.

#### Step 4: Request to TGS

The client sends:

- TGT
- Request for a particular service

to the Ticket Granting Server.

#### Step 5: Service Ticket Generation

The TGS verifies the TGT and issues:

- Service Session Key
- Service Ticket

#### Step 6: Accessing Service

The client sends the Service Ticket to the Service Server.

#### Step 7: Service Authentication

The Service Server validates the ticket and grants access to the requested service.

### Kerberos Authentication Flow

```
Client → AS : Authentication Request

AS → Client : TGT + Session Key

Client → TGS : TGT + Service Request

TGS → Client : Service Ticket

Client → Server : Service Ticket

Server → Client : Access Granted
```

### Features of Kerberos

- Mutual authentication
- Single Sign-On (SSO)
- Passwords are not transmitted over the network
- Protection against replay attacks
- Secure ticket-based authentication

### Conclusion

Kerberos provides secure authentication by using tickets and session keys issued by trusted servers. It is widely used in enterprise networks, distributed systems, and Windows Active Directory environments.

## a) Write Short Note on X.509. \[5\]

### X.509 Certificate

X.509 is an international standard developed by ITU-T for Public Key Infrastructure (PKI). It defines the format of digital certificates used for authentication and secure communication in computer networks. X.509 certificates bind a user's identity with a public key and are issued by a trusted Certificate Authority (CA).

X.509 certificates are widely used in SSL/TLS, HTTPS, secure e-mail, VPNs, and digital signatures.

### Structure of an X.509 Certificate

An X.509 certificate contains the following fields:

| Field | Description |
|---------|-------------|
| Version | Certificate format version |
| Serial Number | Unique number assigned by CA |
| Signature Algorithm | Algorithm used to sign certificate |
| Issuer Name | Name of Certificate Authority |
| Validity Period | Start and expiry date |
| Subject Name | Owner of certificate |
| Subject Public Key | Public key of owner |
| Extensions | Additional information |
| Digital Signature | Signature of CA |

### Working of X.509

1. User generates a public-private key pair.
2. Public key and identity information are sent to the CA.
3. CA verifies the identity of the user.
4. CA issues a digitally signed X.509 certificate.
5. During communication, the certificate is presented to the receiver.
6. The receiver verifies the CA's signature and trusts the public key.

### Applications

- HTTPS websites
- Secure e-mail systems
- VPN authentication
- Digital signatures
- Enterprise security systems

### Conclusion

X.509 provides a standardized framework for digital certificates and enables trusted authentication, confidentiality, and integrity in secure communications.

# b) What is Digital Signature Standard (DSS)? Explain the DSS Approach. \[6\]

### Digital Signature Standard (DSS)

Digital Signature Standard (DSS) is a U.S. government standard developed by NIST for creating and verifying digital signatures. DSS provides authentication, integrity, and non-repudiation of electronic documents.

DSS uses the **Digital Signature Algorithm (DSA)** for generating digital signatures.

### Need for DSS

Digital signatures help to:

- Verify sender identity
- Ensure message integrity
- Prevent repudiation
- Secure electronic transactions

### DSS Approach

The DSS approach consists of two phases:

#### 1. Signature Generation

1. Sender prepares the message.
2. A hash value of the message is generated using SHA.
3. Using the sender's private key and hash value, a digital signature is created.
4. The message and signature are sent to the receiver.

**Process:**

```text
Message
 ↓
Hash Function (SHA)
 ↓
Message Digest
 ↓
Sender's Private Key
 ↓
Digital Signature
```

#### 2. Signature Verification

1. Receiver receives the message and signature.
2. Receiver computes the hash of the received message.
3. Using the sender's public key, the received signature is verified.
4. If both hash values match, the signature is valid.

**Process:**

```text
Received Message
 ↓
Hash Function
 ↓
Digest 1

Digital Signature
 ↓
Sender's Public Key
 ↓
Digest 2

Digest 1 = Digest 2
 ↓
Valid Signature
```

### Features of DSS

- Provides authentication
- Ensures integrity
- Supports non-repudiation
- Uses public key cryptography
- Efficient for digital signature generation

### Applications

- Electronic documents
- E-commerce transactions
- E-governance systems
- Banking applications
- Secure e-mails

### Conclusion

DSS is a standard mechanism for generating and verifying digital signatures. It ensures secure and trustworthy communication by providing authentication, integrity, and non-repudiation.

## b) Explain the Terms. \[6\]

### i) Virus

A virus is a malicious program that attaches itself to a legitimate file or program and replicates when the infected file is executed. It can corrupt data, slow down systems, or damage files.

**Example:** File Infector Virus, Macro Virus.

### ii) Phishing

Phishing is a cyberattack in which attackers send fraudulent emails, messages, or websites to trick users into revealing sensitive information such as passwords, OTPs, or banking details.

**Example:** Fake bank login page requesting account credentials.

### iii) Spoofing

Spoofing is the act of disguising communication from an unknown source as being from a trusted source. Attackers forge IP addresses, email addresses, or websites to deceive users.

**Example:** An email appearing to come from a legitimate bank.

### iv) Mobile Hacking

Mobile hacking refers to unauthorized access to smartphones or mobile devices to steal information, monitor activities, or install malware.

**Example:** Spyware installed through a malicious mobile application.

### v) Internet Pharming

Internet Pharming is an attack that redirects users from legitimate websites to fake websites without their knowledge, usually by manipulating DNS settings.

**Example:** Redirecting a banking website to a counterfeit banking page.

### vi) Cyber Forensics

Cyber Forensics is the process of collecting, preserving, analyzing, and presenting digital evidence related to cybercrimes and security incidents.

**Applications:**
- Crime investigation
- Data recovery
- Fraud detection
- Legal proceedings

### Conclusion

These concepts represent important cyber threats and security practices that organizations and individuals must understand to ensure safe use of digital systems.

2. The infected device becomes a bot.
3. The bot connects to a Command and Control (C&C) server.
4. The Botmaster sends commands to all bots.
5. Bots perform malicious activities simultaneously.

```text
Botmaster
 ↓
C&C Server
 ↓
Bot Network
 ↓
Target Systems
```

### Uses of Botnets

- Distributed Denial of Service (DDoS) attacks
- Spam email distribution
- Credential theft
- Cryptocurrency mining
- Malware propagation

### Impacts

- Network congestion
- Financial loss
- Data theft
- Service disruption

### Prevention

- Install antivirus software
- Regularly update systems
- Avoid suspicious links and downloads

## a) List and Explain Types of Intrusion Detection System (IDS). \[6\]

### Intrusion Detection System (IDS)

An Intrusion Detection System (IDS) is a security mechanism that monitors network traffic and system activities to detect unauthorized access, malicious activities, or policy violations. IDS generates alerts whenever suspicious behavior is detected.

### Types of IDS

#### 1. Network-Based Intrusion Detection System (NIDS)

NIDS monitors network traffic flowing through a network segment. It analyzes packets passing through routers, switches, and gateways to identify malicious activities.

**Example:** Detecting port scanning, DoS attacks, and malware communication.

#### 2. Host-Based Intrusion Detection System (HIDS)

HIDS is installed on individual hosts or servers and monitors system files, logs, processes, and user activities.

**Example:** Detecting unauthorized file modifications or privilege escalation.

### Boltzmann Machine

A Boltzmann Machine is a recurrent neural network consisting of symmetrically connected processing units. It is an energy-based neural network that uses stochastic processing to learn patterns and solve optimization problems. The network derives its name from the Boltzmann distribution used in statistical mechanics.

The main objective of a Boltzmann Machine is to reach a stable state having minimum energy. Unlike Hopfield networks, Boltzmann Machines allow random state changes, which helps them escape local minima.

### Architecture of Boltzmann Machine

A Boltzmann Machine consists of:

1. **Visible Nodes** – Interact with external data and receive inputs.
2. **Hidden Nodes** – Extract features and learn internal representations.
3. **Symmetric Connections** – If node i is connected to node j, then

\\[
W_{ij}=W_{ji}
\\]

4. No self-connections are allowed.

### State Transition Diagram

For a two-neuron Boltzmann Machine, four possible states exist:

| State | Neuron 1 | Neuron 2 |
|---------|----------|----------|
| S1 | +1 | +1 |
| S2 | +1 | -1 |
| S3 | -1 | +1 |
| S4 | -1 | -1 |

The network can move from one state to another according to probability and energy minimization criteria until it reaches a stable minimum-energy state.

```text
 S1(+1,+1)
 / \
 / \
S2(+1,-1) S3(-1,+1)
 \ /
 \ /
 S4(-1,-1)
```

### Comment on Nodes and Connections

- Visible nodes represent the input pattern.
- Hidden nodes capture complex relationships among data.
- Connections are bidirectional and symmetric.
- Network dynamics are governed by an energy function.
- Random neuron updates help avoid local minima.

### Boltzmann Learning Law

The Boltzmann Learning Law adjusts connection weights so that the network learns the probability distribution of the training data.

The weight update rule is:

\\[
\Delta W_{ij}=\eta(P_{ij}^{+}-P_{ij}^{-})
\\]

Where:

- \(\eta\) = Learning rate
- \(P_{ij}^{+}\) = Correlation when data is clamped
- \(P_{ij}^{-}\) = Correlation when network runs freely

### Working

1. Present training pattern to visible units.
2. Compute correlations among neurons.
3. Allow network to run freely.
4. Measure new correlations.
5. Update weights using learning rule.
6. Repeat until convergence.

### Limitations of Boltzmann Machine

1. Training is computationally expensive.
2. Convergence is very slow.
3. Requires large memory.
4. Difficult to scale for large datasets.
5. Hidden unit calculations increase complexity.
6. Not suitable for real-time applications.

### Applications

- Pattern recognition
- Optimization problems
- Image reconstruction
- Feature extraction

### Conclusion

Boltzmann Machines are powerful stochastic neural networks capable of solving optimization and learning tasks through energy minimization. However, their slow learning process and high computational cost limit their practical use.

## False Minima Problem

A Boltzmann Machine attempts to minimize its energy function and reach the lowest energy state. During this process, the network may become trapped in a **local minimum (false minima)** instead of reaching the global minimum.

A false minimum is a stable state whose energy is lower than neighboring states but not the lowest possible energy of the entire network.

### Example

```text
Energy

 ^
 |
 | *
 | * *
 | * * ← False Minima
 | *
 | *
 | *
 | * ← Global Minima
 +-----------------------------> State
```

If the network reaches the false minima, learning stops even though a better solution exists.

### Effects of False Minima

- Incorrect pattern storage
- Poor optimization results
- Reduced learning performance
- Slower convergence

---

## Stochastic Update

To overcome false minima, Boltzmann Machines use **stochastic updating** instead of deterministic updating.

In stochastic updating, a neuron may change its state according to a probability function rather than a fixed rule.

The probability of activation is given by:

\\[
P(X_i=1)=\frac{1}{1+e^{-\Delta E/T}}
\\]

Where:

- \( \Delta E \) = Change in energy
- \( T \) = Temperature parameter

### Features

- Allows random state transitions.
- Helps escape local minima.
- Improves exploration of solution space.
- Essential for simulated annealing.

---

## Simulated Annealing

Simulated Annealing is an optimization technique inspired by the annealing process in metallurgy, where heated metal is slowly cooled to obtain a stable crystalline structure.

In Boltzmann Machines, the temperature is initially kept high and gradually reduced. At high temperatures, neurons can make random transitions. As temperature decreases, the network settles into a low-energy state.

### Working Principle

- High temperature → More random state changes.
- Low temperature → More stable decisions.
- Final temperature → Global minimum is approached.

---

## Simulated Annealing Algorithm

### Step 1

Initialize:

- Weight matrix
- Initial state
- High temperature \(T\)

### Step 2

Calculate network energy.

### Step 3

Select a neuron randomly.

### Step 4

Compute change in energy:

\\[
\Delta E
\\]

### Step 5

If

\\[
\Delta E < 0
\\]

accept the state change.

### Step 6

If

\\[
\Delta E > 0
\\]

accept the change with probability:

\\[
P=e^{-\Delta E/T}
\\]

### Step 7

Repeat for several iterations.

### Step 8

Reduce temperature gradually:

\\[
T=T\times \alpha
\\]

where \(0<\alpha<1\)

### Step 9

Continue until temperature approaches zero.

### Step 10

Network converges to minimum-energy state.

### Flow of Simulated Annealing

```text
Initialize Network
 ↓
Set High Temperature
 ↓
Random State Update
 ↓
Compute Energy Change
 ↓
Accept / Reject State
 ↓
Reduce Temperature
 ↓
Repeat
 ↓
Reach Stable State
```

---

## Advantages of Simulated Annealing

1. Escapes false minima effectively.
2. Approaches global optimum solution.
3. Suitable for complex optimization problems.
4. Improves learning accuracy.
5. Works well in large search spaces.

## Disadvantages of Simulated Annealing

1. Computationally expensive.
2. Slow convergence.
3. Requires careful temperature scheduling.
4. Performance depends on cooling rate.
5. Large execution time for complex problems.

## Conclusion

False minima are major obstacles in Boltzmann Machines. Stochastic updating and simulated annealing allow the network to escape local minima and move toward the global minimum, thereby improving optimization and learning performance.

LVQ uses prototype vectors that represent different classes. During training, prototypes move toward correctly classified samples and away from incorrectly classified samples.

### Architecture of LVQ

```text
Input Layer
 │
 │
Competitive Layer
(Prototype Vectors)
 │
 │
Output Class Layer
```

- Input layer receives feature vectors.
- Competitive layer contains prototype neurons.
- Output layer represents classes.

\\]

Input pattern:

\\[

\\]

is applied to the network.

\\[
D_j=\sqrt{\sum (X_i-W_{ij})^2}

\\[
W_{new}=W_{old}-\alpha(X-W_{old})
\\]

### Step 6: Reduce Learning Rate

\\[
\alpha=\alpha-\Delta\alpha
\\]

### Step 7: Repeat

Continue until all patterns are classified properly.

Not only the winning neuron but also neighboring neurons learn simultaneously.

### 6. Feature Extraction

Important characteristics of input data are automatically identified.

### 7. Robustness

Feature maps can handle noisy and incomplete data effectively.

```text
 │

 │
 ┌───────────────┐

 Competitive Layer
```

### Components

- Neighborhood Structure
- Weight Connections

## Competitive Learning

Competitive Learning is an unsupervised learning technique in which neurons compete with each other to respond to an input pattern. Only one neuron (or a small group of neurons) wins the competition and updates its weights.

The learning process allows neurons to specialize in different regions of the input space.

---

## Components of Competitive Learning

### 1. Input Layer

Receives input feature vectors.

### 2. Competitive Layer

Contains neurons competing to become the winner.

### 3. Competition Mechanism

Determines which neuron best matches the input pattern.

### 4. Learning Rule

Updates weights of the winning neuron.

### 5. Neighborhood Function

Allows neighboring neurons to learn in SOM networks.

---

## Winner-Takes-All (WTA)

Winner-Takes-All is the most common competition strategy.

The neuron with the highest activation or minimum distance wins the competition.

Only the winning neuron updates its weights.

```text
Input Pattern
 ↓
Neuron 1 → 0.7
Neuron 2 → 0.9 ← Winner
Neuron 3 → 0.4
 ↓
Update only Neuron 2
```

---

## Limitations of Competitive Learning

1. Dead neuron problem.
2. Sensitive to initial weights.
3. Slow convergence.
4. No class label information.
5. May produce poor clusters if training data is inadequate.

---

## Difference Between Competitive Learning and Hebbian Learning

| Parameter | Competitive Learning | Hebbian Learning |
|------------|---------------------|------------------|
| Learning Type | Unsupervised | Unsupervised |
| Weight Update | Only winner updates | All active neurons update |
| Competition | Present | Absent |
| Objective | Clustering and feature mapping | Strengthening neuron associations |
| Winner-Takes-All | Used | Not used |
| Applications | SOM, LVQ | Associative memory, Hopfield Network |

---

## Conclusion

Competitive Learning enables neurons to specialize through competition and forms the basis of SOM and LVQ networks. The Winner-Takes-All strategy ensures efficient clustering, while Hebbian learning focuses on strengthening associations between simultaneously active neurons.

## a) Explain the Backpropagation Learning Algorithm in Detail. Derive the Weight Update Rule and Discuss Its Advantages and Limitations. \[9\]

## Backpropagation Algorithm

Backpropagation is a supervised learning algorithm used for training **Multi-Layer Perceptron (MLP)** networks. It adjusts the weights of the network by propagating the error backward from the output layer to the hidden layer.

The objective of Backpropagation is to minimize the difference between the actual output and the desired output.

### Architecture of Backpropagation Network

```text
Input Layer
 ↓
Hidden Layer(s)
 ↓
Output Layer
```

Each neuron is connected through weighted links and learns by updating these weights.

---

## Working of Backpropagation

### Step 1: Initialize Weights

Initialize all weights with small random values.

### Step 2: Present Input Pattern

Input vector is applied to the input layer.

\\[
X=(x_1,x_2,\ldots,x_n)
\\]

### Step 3: Forward Propagation

Compute net input for each neuron.

\\[
Net_j=\sum W_{ij}X_i
\\]

Calculate output using activation function.

\\[
O_j=f(Net_j)
\\]

### Step 4: Compute Error

\\[
E=\frac{1}{2}\sum (T_k-O_k)^2
\\]

Where:

- \(T_k\) = Desired output
- \(O_k\) = Actual output

### Step 5: Backward Propagation

Error is propagated backward from output layer to hidden layer.

### Step 6: Update Weights

Weights are modified to reduce error.

### Step 7: Repeat

Training continues until minimum error is achieved.

---

## Derivation of Weight Update Rule

Error function:

\\[
E=\frac{1}{2}(T-O)^2
\\]

Weight correction:

\\[
\Delta W=-\eta\frac{\partial E}{\partial W}
\\]

Where:

- \(\eta\) = Learning rate

Using gradient descent:

\\[
\Delta W=\eta \delta X
\\]

where

\\[
\delta=(T-O)f'(Net)
\\]

Therefore,

\\[
W_{new}=W_{old}+\eta\delta X
\\]

This equation is known as the **Backpropagation Weight Update Rule**.

---

## Backpropagation Training Algorithm

### Phase 1: Forward Pass

1. Present input pattern.
2. Compute outputs of hidden neurons.
3. Compute outputs of output neurons.

### Phase 2: Error Computation

4. Calculate output error.
5. Determine error signals.

### Phase 3: Backward Pass

6. Propagate error backward.
7. Update output layer weights.
8. Update hidden layer weights.

### Phase 4: Iteration

9. Repeat for all training samples.
10. Stop when error becomes minimum.

---

## Advantages of Backpropagation

1. Learns complex nonlinear relationships.
2. High prediction accuracy.
3. Suitable for multilayer networks.
4. Can solve classification and regression problems.
5. Widely used in practical applications.

## Limitations of Backpropagation

1. Slow training process.
2. May get trapped in local minima.
3. Requires large training datasets.
4. Sensitive to learning rate selection.
5. Computationally expensive for large networks.

---

## Applications

- Handwritten character recognition
- Speech recognition
- Medical diagnosis
- Image classification
- Financial forecasting

### Conclusion

Backpropagation is one of the most widely used supervised learning algorithms. By minimizing error through gradient descent and iterative weight updates, it enables neural networks to learn complex patterns and perform accurate predictions.

## Particle Swarm Optimization (PSO)

Particle Swarm Optimization (PSO) is a population-based optimization technique inspired by the social behavior of birds flocking and fish schooling. It was introduced by **entity\["people","James Kennedy","Particle Swarm Optimization co-inventor"\]** and **entity\["people","Russell Eberhart","Particle Swarm Optimization co-inventor"\]** in 1995.

In PSO, each solution is represented by a particle that moves through the search space to find the optimum solution.

---

## Basic Concept

Each particle has:

1. Position
2. Velocity
3. Personal Best Position (Pbest)
4. Global Best Position (Gbest)

The particles continuously adjust their positions based on their own experience and the experience of neighboring particles.

---

## Working Principle

### Step 1: Initialize Particles

Generate random particles with positions and velocities.

### Step 2: Evaluate Fitness

Calculate the fitness of every particle.

### Step 3: Update Personal Best

If the current position is better than previous best,

update:

\\[
Pbest = Current Position
\\]

### Step 4: Update Global Best

Select the best particle among all particles.

\\[
Gbest
\\]

### Step 5: Update Velocity

\\[
V_{i}=wV_{i}+c_1r_1(Pbest-X_i)+c_2r_2(Gbest-X_i)
\\]

Where:

- \(w\) = Inertia weight
- \(c_1,c_2\) = Learning coefficients
- \(r_1,r_2\) = Random values

### Step 6: Update Position

\\[
X_i=X_i+V_i
\\]

### Step 7: Repeat

Continue until optimum solution is found.

---

```text

 ↓

 ↓

 ↓

 ↓

 Best Solution
```

## Limitations of PSO

---

## Applications

Particle Swarm Optimization is a powerful population-based optimization technique that uses collective intelligence to search for optimal solutions. Its simplicity and fast convergence make it popular in engineering and AI applications.

Net input:

\\[
Net=\sum W_iX_i
\\]

Threshold function:

\\[
Y=
\begin{cases}
1, & Net \ge \theta\\
0, & Net < \theta
\end{cases}
\\]

Where:

- \(\theta\) = Threshold value

---

### Step 1

Receive binary inputs.

### Step 2

Multiply each input by its weight.

### Step 3

Calculate weighted sum.

### Step 4

Compare with threshold value.

### Step 5

Generate output.

Since

\\[
Net\ge\theta

Output:

\\[
Y=1
\\]

- Neural network fundamentals
- Digital circuit design

A Self-Organizing Map (SOM), also called a Kohonen Network, is an unsupervised neural network that transforms high-dimensional input data into a low-dimensional feature map while preserving topological relationships.

## Architecture of SOM

The network consists of:

### Input Layer

Receives feature vectors.

### Competitive Layer

Neurons are arranged in a one-dimensional or two-dimensional grid.

```text
Input Layer
x1 x2 x3 ... xn
 │ │ │
 ▼ ▼ ▼

O O O O
O O O O
O O O O

Competitive Layer
(Feature Map)
```

Each neuron possesses a weight vector of the same dimension as the input vector.

## KSOFM Training Algorithm

### Step 1: Initialize Weights

Assign small random values.

### Step 2: Present Input Vector

\\[

\\]

Weights of the winner and neighboring neurons are adjusted toward the input pattern.

In a **Hopfield Neural Network (HNN)**, the **Hebbian Learning Rule** is used to calculate the weight matrix that stores the desired patterns in memory.

The basic idea of Hebbian learning is:

> **"Neurons that fire together, wire together."**

If two neurons have the same activation state, the connection between them becomes stronger.

## Hebbian Rule in Hopfield Network

Suppose a pattern is:

\\[
X=\[x_1,x_2,\dots,x_n\]
\\]

where each element is bipolar:

\\[
x_i \in \{-1,+1\}
\\]

The weight between neurons \(i\) and \(j\) is calculated as:

\\[
w_{ij}=x_i x_j
\\]

For multiple patterns:

\\[
W=\sum_{p=1}^{m} X_p^T X_p
\\]

After calculating:

\\[
w_{ii}=0
\\]

because a neuron cannot have a connection with itself.

### 1. Pattern Storage

Hebbian learning stores patterns directly into the weight matrix.

### 2. Associative Memory

The network can recall a complete pattern from a partial or noisy input.

### 3. Symmetric Weights

Hebbian learning naturally produces:

\\[

### 4. Energy Minimization

The stored patterns become stable states (local minima) of the Hopfield energy function.

Boltzmann Machines use **Stochastic Learning** (Probabilistic Learning), not simple Hebbian learning.

The weights are updated using a modified Hebbian rule based on probabilities.

---

## Why Not Hebbian Learning?

In Hopfield Network:

- Neurons are deterministic.
- Output is either +1 or -1 directly.
- Network converges to a stable state.

In Boltzmann Machine:

- Neurons are stochastic (random).
- A neuron may become ON or OFF according to probability.
- Simulated annealing is used to reach the minimum energy state.

Therefore simple Hebbian learning is insufficient.

---

## Weight Update Rule in Boltzmann Machine

The weight change is:

\\[
\Delta w_{ij}
=
\eta
(\langle s_i s_j\rangle^{+}
-
\langle s_i s_j\rangle^{-})
\\]

where

\\[
\eta = \text{learning rate}
\\]

\\[
\langle s_i s_j\rangle^{+}
\\]

= correlation when data is clamped (positive phase)

\\[
\langle s_i s_j\rangle^{-}
\\]

= correlation when network runs freely (negative phase)

---

## Positive Phase

Input pattern is applied to the network.

Desired states are forced.

The network learns what the correct answer should look like.

---

## Negative Phase

Network is allowed to run freely.

The network generates its own states.

The difference between positive and negative phases is used for learning.

---

## Activation Function in Boltzmann Machine

Instead of

\\[
x_i=
\begin{cases}
+1,& net_i>0\\
-1,& net_i<0
\end{cases}
\\]

Boltzmann Machine uses probability:

\\[
P(s_i=1)
=
\frac{1}{1+e^{-net_i/T}}
\\]

where

\\[
T = \text{Temperature}
\\]

Higher temperature → more randomness

Lower temperature → less randomness

---

## Role of Simulated Annealing

Boltzmann Machine is inspired by statistical mechanics.

Training uses:

1. High temperature
2. Random exploration
3. Gradual cooling
4. Convergence to minimum energy state

This process is called **Simulated Annealing**.

| Annealing | No | Yes |

**Hopfield Network uses Hebbian Learning Rule (outer product learning), whereas Boltzmann Machine uses Stochastic Learning based on probability distributions and simulated annealing to update weights and minimize network energy.**

Suppose

### Next State

### Step 1
Define states

\\[
S_1=\[+1,+1\]
\\]

\\[
S_2=\[+1,-1\]
\\]

\\[
S_3=\[-1,+1\]
\\]

\\[

### Step 2
Find weight matrix using Hebbian rule.

### Step 3
For each state calculate

\\[
Net_i=\sum w_{ij}x_j
\\]

### Step 4
Apply activation function.

### Step 5
Obtain next state.

### Step 6
Check whether the state remains unchanged (stable state) or moves to another state.

So the formula

\\[
Net_i=\sum w_{ij}x_j
\\]

is **not used for training**. It is used for **updating neurons and finding the next state during recall/testing of the Hopfield Network**. This is the most important formula in HNN state-transition derivations.

+1, & net_i>0\\

### Step 1: Compute Net Input

\\[

-1,& Net_i<0
\end{cases}

Repeat until the state no longer changes.

## Does Boltzmann Machine Use This?

**No.**

Boltzmann Machines do compute a net input:

\\[
Net_i=\sum_j w_{ij}x_j
\\]

but they **do not directly apply the sign activation function**.

Instead they use a probability:

\\[
P(x_i=1)
=
\frac{1}{1+e^{-Net_i/T}}
\\]

where \(T\) is the temperature.

So:

| Network | Net Input Formula | Activation |
|----------|----------|----------|
| Hopfield Network | \(\sum w_{ij}x_j\) | Sign function (+1/-1) |
| Boltzmann Machine | \(\sum w_{ij}x_j\) | Probabilistic sigmoid |
| McCulloch-Pitts Neuron | \(\sum w_{ij}x_j\) | Threshold (0/1) |
| Perceptron | \(\sum w_{ij}x_j+b\) | Step function |
| ANN (Modern) | \(\sum w_{ij}x_j+b\) | Sigmoid, ReLU, Tanh, etc. |

### Exam Point

For **Hopfield Network derivations**, whenever you see:

1. Calculate \(Net_i=\sum w_{ij}x_j\)
2. Apply

\\[
x_i=
\begin{cases}
+1,& Net_i>0\\
-1,& Net_i<0
\end{cases}
\\]

3. Obtain next state

you are performing the **state update (recall process) of a Hopfield Network**. This is the standard method used in HNN numericals.
